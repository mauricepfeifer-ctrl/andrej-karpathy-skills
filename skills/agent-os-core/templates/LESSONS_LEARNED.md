# Lessons Learned

Distilled lessons, verified by human review. Each entry was an open error that became a confirmed learning.

**Status meanings:**
- `PENDING` — drafted by `/improve`, not yet verified
- `VERIFIED` — human confirmed this lesson
- `REJECTED` — human rejected this lesson
- `PROMOTED` — lesson became a rule in `CLAUDE.md` / `AGENTS.md`

**Format:**
```
## [YYYY-MM-DD] [LESSON TITLE]
**Statement:** [one clear sentence]
**Based on:** [error entries — dates/titles]
**Verified by:** [human] on [date]
**Status:** PENDING | VERIFIED | REJECTED | PROMOTED
**Promoted to:** [CLAUDE.md section] | N/A
```
