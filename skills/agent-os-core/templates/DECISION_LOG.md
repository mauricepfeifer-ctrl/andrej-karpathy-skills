# Decision Log

Document non-obvious decisions made during agent work.

**Why:** Decisions that seem obvious now cause confusion later. Logging them creates an audit trail and helps identify recurring decision patterns.

**Safety:** Do not log private, legal, or secret data.

**Format:**
```
## [YYYY-MM-DD] [DECISION TITLE]
**Context:** [what situation triggered this decision]
**Options considered:** [brief list]
**Decision:** [what was chosen]
**Reasoning:** [why]
**Revisit if:** [condition under which this should be reconsidered]
```
